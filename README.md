# Аудит продуктовых метрик и статистический анализ интернет-магазина

Практический аудит метрик интернет-магазина по логам суточной активности пользователей ($n = 20$): поиск аномалий, моделирование распределений, оценка точности среднего и проверка гипотез.

**Инструменты и стек:** Python, Scipy, Pandas, прикладная статистика, проверка гипотез, A/B-тестирование

---

## Задачи проекта

1. **Экспресс-аудит метрик:** расчет общей и условной конверсии (desktop / mobile), проверка независимости событий, выбор устойчивой метрики «типичного» чека (среднее, медиана, мода).
2. **Поиск аномалий:** квартили, межквартильный размах ($IQR$) и правило Тьюки $1.5 \times IQR$.
3. **Моделирование распределений:** формула Бернулли и мода биномиального распределения для промо-кампании, нормальный закон и $z$-оценки для настройки серверных лимитов.
4. **ЗБЧ и ЦПТ:** стандартная ошибка среднего ($SE$), доверительные интервалы, влияние размера выборки на точность.
5. **Проверка гипотез:** формулировка $H_0$ / $H_1$, выбор двухвыборочного t-теста Стьюдента / Уэлча, интерпретация p-value и ошибки I рода.

---

## Ключевые результаты

* Общая конверсия — **55%**, конверсия на десктопе — **90.9%**, на мобильных — **11.1%**: события зависимы, в мобильной версии сайта выявлена критическая проблема с оформлением заказов.
* Среднее ($2054.75$ руб.) > медиана ($422.5$ руб.) > мода ($0$ руб.) — сильная правосторонняя асимметрия; для финансовой отчетности рекомендована медиана.
* По правилу $1.5 \times IQR$ (порог $9125$ руб.) найден выброс — заказ на **12 000 руб.**; обоснован отказ от удаления в пользу логарифмирования / винзорирования.
* Стандартная ошибка среднего чека — **≈ 700.82 руб.**; при росте выборки с 20 до 200 она снизится в $\sqrt{10} \approx 3.16$ раза.
* При $p\text{-value} = 0.012 < \alpha = 0.05$ нулевая гипотеза отклонена — различия во времени на сайте статистически значимы.
